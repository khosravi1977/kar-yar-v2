# نقشهٔ راه کار یار

## فاز اول (این نسخه — آزمایشی)
- رابط فارسی/RTL/جلالی کامل، CRUD کارها، انتقال/پیگیری، سوابق، جست‌وجو و فیلتر پایه
- IndexedDB + مهاجرت امن localStorage با پشتیبان و بازگردانی
- PWA نصب‌شدنی، آفلاین، به‌روزرسانی کنترل‌شده، فونت وزیرمتن
- پشتیبان‌گیری/بازیابی (فرمت جدید + سازگاری قدیمی)، لاگ، حذف کامل دو مرحله‌ای

## عمداً در فاز اول پیاده‌سازی نمی‌شود
- هر نوع API/سرور، Sync Queue، احراز هویت، اشتراک چندنفره
- Push و اعلان پس‌زمینه
- تست‌های خودکار Vitest/Playwright و CI (اجرا نشده — محدودیت این تحویل)
- باندلر Vite و تقسیم vendor

## فاز دوم (پیشنهادی)
1. افزودن Vitest + تست‌های واحد برای idb/repository/migration/quota/logger با پوشش خط ۸۰٪/شاخه ۷۵٪
2. Playwright E2E: ایجاد-بازیابی آفلاین، انتقال تاریخ، مهاجرت (seed واقعی localStorage)
3. CI (GitHub Actions): lint صفر + تست + بیلد + سنجش حجم gzip (سقف ۱۵۰KB) + Lighthouse
4. ارتقای id به UUID v4 با migration schemaVersion=2 و نگاشت parentId/history
5. سنجش سنجه‌های محصولی به روش محلی (بدون ارسال داده)

## فاز سوم (مشروط به معیارهای عبور)
- API و همگام‌سازی طبق docs/api-contract.md با last-write-wins بر اساس updatedAt سرور
- فقط پس از: پایداری فاز اول، بازخورد واقعی کاربران دربارهٔ نبود همگام‌سازی، و تأیید کاربر
