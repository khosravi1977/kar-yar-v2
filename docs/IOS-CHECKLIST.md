# چک‌لیست آزمون iOS/Safari — کار یار ۴.۱ (۱۰ دقیقه، توسط مالک)
محدودیت ثبت‌شده (BUG-07): همهٔ آزمون‌های خودکار روی Chrome/اندروید و دسکتاپ اجرا شده‌اند؛ Safari/iOS فقط با این چک‌لیست دستی آزمایش می‌شود. هر مورد ✓ یا ✗ (با توضیح) را کنارش بنویسید و فایل را برایم بفرستید.

## پیش‌نیاز
- [ ] iPhone/iPad واقعی با Safari نسخهٔ 16.4 به بالا

## نصب
1. [ ] باز کردن `https://khosravi1977.github.io/kar-yar-v2/` در Safari — صفحه بدون خطا باز شود
2. [ ] Share ⬆️ → **Add to Home Screen** → نام «کار یار ۴» و آیکون بنفش دیده شود → Add
3. [ ] آیکون روی صفحهٔ اصلی ساخته شود و اپ **تمام‌صفحه** (بدون نوار Safari) باز شود

## آفلاین
4. [ ] یک کار بسازید → حالت هواپیما را روشن کنید → اپ را ببندید و دوباره باز کنید → کارها دیده شوند
5. [ ] در حالت آفلاین یک کار جدید ثبت کنید → بنر «اتصال اینترنت قطع است» بالای صفحه بیاید ولی ذخیره انجام شود
6. [ ] حالت هواپیما را خاموش کنید → بنر محو شود

## پوسته و رابط
7. [ ] تنظیمات ← پوستهٔ برنامه ← «تاریک» → کل صفحه تاریک و خوانا شود (کنتراست متن‌ها خوب)
8. [ ] «خودکار (سیستم)» → با تغییر Dark Mode گوشی، برنامه عوض شود
9. [ ] فونت‌ها فارسی (وزیرمتن) و اعداد شمسی درست نمایش داده شوند
10. [ ] تاریخ امروز در سربرگ با تقویم شمسی دستگاه بخواند
